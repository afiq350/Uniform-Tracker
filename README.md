# UNIFORM TRACKER
### Commander Management System

**A Web-Based Commander Management, Attendance Tracking and Performance Monitoring System**

---

## 1. Project Overview

Uniform Tracker is a web-based management system developed to simplify and organize the management of commanders within a uniformed organization.

The system provides a centralized platform for officers to manage commander information, monitor attendance, record assessment results and generate performance reports.

It also allows commanders to access their personal information, monitor attendance records, review assessment results and manage their account passwords.

Uniform Tracker aims to improve administrative efficiency, data organization, accessibility and performance monitoring through a simple and user-friendly interface.

## 2. Project Objectives

The main objectives of Uniform Tracker are:

1. To centralize commander information and records in one management system.
2. To simplify attendance recording and monitoring.
3. To provide an organized platform for recording and reviewing assessment results.
4. To help officers monitor commander performance through reports and analytics.
5. To provide commanders with access to their personal records.
6. To improve the efficiency of administrative management within the organization.

## 3. System Features and Functionalities

Uniform Tracker provides two main user roles: Officer and Commander.

### 3.1 Officer Module

The Officer has administrative access to manage the overall system.

**Dashboard**
- View overall system statistics.
- Monitor commander information.
- Review attendance and assessment summaries.
- Access the main system modules.

**Commander Management**
- Add new commander records.
- Edit existing commander information.
- View registered commanders.
- Delete commander accounts.
- Assign commanders to their respective companies.
- Manage commander account status.

**Attendance Management**
- Record commander attendance.
- Select attendance activities.
- Update attendance records.
- Monitor attendance status.
- View attendance information.

**Grade Management**
- Record commander assessment marks.
- Select assessment categories.
- Edit existing grade records.
- Monitor commander assessment performance.

**Reports and Analytics**
- View overall attendance statistics.
- Review assessment performance.
- Monitor commander records.
- Filter reports by available criteria.
- View data through charts and tables.

**Account Management**
- Reset commander passwords.
- Manage account access.
- Change personal account password.

### 3.2 Commander Module

Commanders have restricted access to their own information and records.

**Personal Dashboard**
- View personal account information.
- View assigned company.
- Monitor personal statistics.
- Access available system modules.

**Personal Attendance**
- Submit personal attendance information.
- View personal attendance records.
- Monitor attendance history.

**Personal Grades**
- View personal assessment results.
- Review marks and grades.
- Monitor individual performance.

**Personal Reports**
- View personal performance information.
- Review attendance summaries.
- Monitor assessment results.

**Account Settings**
- Set a password during the first login.
- Change personal account password.

### 4.2 Officer Dashboard

After logging in, the Officer can access the main dashboard.

The dashboard provides an overview of the system, including available statistics and management modules.

### 4.3 Officer Navigation Menu

The Officer has access to the following modules:

| Module | Description |
|---|---|
| Dashboard | Displays overall system statistics |
| Commander Management | Registers, updates, views and deletes commander accounts |
| Attendance | Manages commander attendance records |
| Grades | Records and manages assessment marks |
| Reports & Analytics | Reviews overall attendance and performance reports |
| Change Password | Updates the Officer's account password |

### 4.4 Commander Account Registration

The Officer is responsible for registering new commanders.

Registration process:

1. Open Commander Management.
2. Select the option to add a new commander.
3. Enter the Commander's 10-digit ID.
4. Enter the Commander's full name.
5. Select the assigned company.
6. Set the account status.
7. Save the new commander record.

The Commander can then use the registered ID to access the system and complete the first-time password setup, if required.

### 4.5 Officer Administrative Responsibilities

The Officer is responsible for:

- Maintaining commander information.
- Managing attendance records.
- Recording assessment results.
- Monitoring overall performance.
- Reviewing reports and analytics.
- Resetting commander passwords when necessary.
- Managing commander account status.

## 5. Commander Access Guide

Commanders have access to their personal information and assigned system functions.

### 5.1 Commander Login

To access the system as a Commander:

1. Open the Uniform Tracker website.
2. Enter the registered 10-digit Commander ID.
3. Enter the account password.
4. Click the Login button.
5. Upon successful login, the system redirects the Commander to the personal Dashboard.

For first-time login, the Commander must complete the password setup process if the account requires it.

### 5.2 First-Time Password Setup

1. Enter the registered Commander ID.
2. Follow the first-time password setup process.
3. Enter a new password.
4. Confirm the new password.
5. Save the password.
6. Return to the login page if required.
7. Log in using the new password.

### 5.3 Commander Navigation Menu

The Commander has access to the following modules:

| Module | Description |
|---|---|
| Dashboard | Displays personal information and statistics |
| Attendance | Submits and views personal attendance |
| Grades | Views personal assessment results |
| Reports & Analytics | Reviews personal performance information |
| Change Password | Changes personal account password |

**Note:** Commander accounts do not have access to Commander Management or other commanders' private records.

## 6. System User Flow

Uniform Tracker provides separate access and functions for Officers and Commanders.

### 6.1 Overall System Flow

1. Open the Uniform Tracker website.
2. The system displays the Login Page.
3. Enter the registered User ID and password.
4. The system validates the login information.
5. The user is redirected according to their assigned role.
6. The user accesses the available system modules.
7. The user logs out after completing the required activities.

### 6.2 Officer Workflow

**Step 1: Officer Login**
- Open the login page.
- Enter the authorized Officer ID and password.
- Access the Officer Dashboard.

**Step 2: Register Commanders**
- Navigate to Commander Management.
- Add new commander information.
- Assign a company.
- Save the commander account.

**Step 3: Manage Attendance**
- Open the Attendance module.
- Select a commander.
- Select the attendance date and activity.
- Record the attendance status.
- Save the attendance record.

**Step 4: Manage Grades**
- Open the Grades module.
- Select a commander.
- Choose an assessment category.
- Enter the assessment date and marks.
- Save the assessment record.

**Step 5: Monitor Performance**
- Navigate to Reports & Analytics.
- Review attendance statistics.
- Review assessment performance.
- Use available search and filtering functions.

**Step 6: Account Management**
- Change the Officer password when necessary.
- Reset Commander passwords when required.

### 6.3 Commander Workflow

**Step 1: Commander Login**
- Open the login page.
- Enter the registered 10-digit Commander ID.
- Complete the required password setup if this is the first login.

**Step 2: Access Personal Dashboard**
- View personal account information.
- Check assigned company.
- Review personal statistics.

**Step 3: Attendance**
- Open the Attendance module.
- Submit personal attendance information.
- View personal attendance history.

**Step 4: View Grades**
- Navigate to the Grades module.
- Review assessment results.
- Monitor individual performance.

**Step 5: View Reports**
- Open Reports & Analytics.
- Review personal attendance and performance information.

**Step 6: Change Password**
- Navigate to Change Password.
- Enter the current password.
- Enter and confirm the new password.
- Save the changes.
